Apple · iPhone / iPad

Add MENEI to your Home screen

  1. Open this link in Safari. If it opens inside a message or social app, copy the link and paste it into Safari.
  2. Tap Open MENEI above. Add the app itself, rather than this guide.
  3. Tap Safari’s Share button (square with an upward arrow). Depending on your layout, it may be inside the More menu.
  4. Choose Add to Home Screen. Scroll the action list or use Edit Actions if needed.
  5. Keep the name MENEI. If Open as Web App appears, turn it on. Tap Add.
  6. Open the new MENEI icon and complete the steps below.

Home-screen installation is required for iPhone/iPad closed-app push notifications. Web Push requires iOS/iPadOS 16.4 or later and supported browser features. Keep your system updated.

Android · Samsung / Pixel / others

Add MENEI to your Home screen

  1. Open this link in Chrome. If it opens inside another app, copy the link into Chrome.
  2. Tap Open MENEI above.
  3. Tap Chrome’s ⋮ menu.
  4. Choose Install and create shortcut → Install. Other Chrome versions show Install app or Add to Home screen.
  5. Confirm Install or Add. Allow adding the icon if your launcher asks.
  6. Open the MENEI icon and complete setup below.

Chrome can also run MENEI in a regular tab. Notification permission is a separate step.

Both platforms · Cloud features

1. Create your MENEI account

  1. Open MENEI → Settings → MENEI account & cloud sync.
  2. Enter your email and password, then tap Create account. Already have a live MENEI account? Use Sign in.
  3. If asked to confirm your email, open the confirmation email and follow its link. Check Spam/Junk if necessary.
  4. Return to the Home-screen app and sign in if needed. An email link may open a separate browser window; return to the installed icon afterward.
  5. Wait for Up to date or Synced. Use the same MENEI account on other devices.

Your MENEI account includes cloud sync. You do not enter a server address, API key or cloud provider credentials. Private-preview accounts may be separate from existing live accounts; do not create a replacement account to recover missing history. Ask the person who invited you if unsure.

Saved records can reopen offline after initial loading. Account creation, sync, AI search and push setup need a connection. Confirm each device has synced before expecting changes on the other.

Both platforms · Your preferences

2. Health notice, profile and units

  1. Read and acknowledge the first-use health notice.
  2. In Settings → Your profile, enter your details and goals.
  3. Choose Measurement system → US customary or Metric, then Save profile. Workout/body weights and compatible ingredient/shopping amounts follow this choice; nutrition macros stay in grams.
  4. Consider your limitations, injuries and medical advice before selecting exercises. MENEI provides general guidance, not medical care.

Both platforms · Training setup

3. Gym equipment and program

  1. Go to Settings → Your gyms → + Gym. Enter the gym name, city and exact address.
  2. Tap Search location with AI for built-in research. Review the exact branch, listed equipment and separately labeled estimates.
  3. Choose the gym type, preview suggestions and add matching items to the checklist. Correct missing/incorrect equipment, attachments and load limits, then Save gym.
  4. In Lifting & running options, choose your split, training style and dates. Preview the program and Save this program. Set gym schedules if you use multiple locations.
  5. During training, enter actual load, reps and RIR, then check Done. Next-set advice updates from your entry; apply suggestions when appropriate.

AI research is limited to the first 20 beta accounts, five attempts each, 100 total including prior usage. A full beta shows a waitlist message. Manual setup remains available. Estimated equipment is not verified branch inventory; review sources and correct the checklist.

Both platforms · Food setup

4. Nutrition preferences

  1. Open Settings → Nutrition options. Review targets, diet, household servings and allergies/exclusions. Save your choices.
  2. Open Nutrition, preview a meal plan and save it. Check ingredients and product labels yourself; suggestions cannot guarantee allergen safety.
  3. Record actual purchases in the shopping list and choose Cook when preparing a meal. Review pantry and leftovers before entering purchases twice.

Optional: Nutrition → Recipes → Upload recipes accepts compatible recipe JSON files or pasted JSON. Preview before adding. Website-link and photo recipe import are not included.

Both platforms · Reminder timing

5. Save your workout start time

  1. Settings → Workout time & reminders: choose your usual workout start time and time zone, then Save workout time.
  2. In Notifications, keep workout reminders selected and save reminder preferences. Meal reminders are optional and use their separate reminder time.
  3. Make sure an upcoming lifting/running workout is saved and not completed or skipped. Stay connected until it has synced.
  4. Enable notifications using the platform steps below. Repeat permission setup on every device where you want alerts.

Workout reminders arrive about one hour before the saved start time. To test a real reminder, choose a workout whose one-hour alert time has not already passed. Phone, network and scheduler delays are possible; this is not an exact alarm.

Apple · Manual permission

6A. Enable iPhone reminders

  1. Complete Home-screen installation and open MENEI from its icon.
  2. Sign in. In MENEI Settings → Notifications, tap Enable push and choose Allow.
  3. iPhone Settings → Notifications → MENEI: allow notifications, select Lock Screen, Notification Center and Banners as desired, and enable Sounds.
  4. If Focus or Do Not Disturb silences alerts, allow MENEI in that Focus or turn it off for testing. Check notification volume and Silent Mode.
  5. Return to MENEI and run the two tests below.

No permission prompt? Check that you opened the installed Home-screen app on a supported system. MENEI cannot allow notification permission on your behalf.

Android · Manual permission

6B. Enable Android reminders

  1. MENEI → Settings → Notifications → Enable push → Allow.
  2. If Android separately asks to allow notifications for Chrome or the installed MENEI app, allow them.
  3. If blocked, open Chrome at the MENEI address → site controls beside the address → Permissions → Notifications → Allow. Chrome Settings → Site settings → Notifications also lists sites.
  4. For sound/pop-ups: Android Settings → Apps → MENEI or Chrome → Notifications. On Samsung, find this site’s category if listed, select Alert, and enable Show as pop-up, sound and vibration as desired.
  5. Check notification volume and Do Not Disturb, then run the tests below.

Menus vary. If Samsung hides categories, check Notifications → Advanced settings → Manage notification categories for each app. Change battery/background restrictions only if delivery stays delayed, not as a routine requirement.

Both platforms · Check delivery

7. Test notifications

  1. Tap Test device notification or Test notification now. This checks local permission/display, not server delivery.
  2. Tap Test with app closed · 2 min. Close/background MENEI, keep your phone online and allow about 2–3 minutes. Do not force-stop the app/browser in system settings.
  3. Check for a MENEI notification. If visible without sound, adjust sound, Focus or category settings above.

No alert? Reopen MENEI, confirm sign-in/sync and device permission, then retry. If the service says unavailable, report it to the person who invited you. Creating another account or changing keys is not a fix.

Both platforms · Open-app sounds

8. Rest-timer sound

  1. Checking a set Done starts rest automatically: 60 seconds between sets; 3 minutes after all sets of an exercise or superset pair. The completion popup closes at zero.
  2. Keep rest sound unmuted or tap Mute sound. A tap inside the app may be needed to allow browser audio.
  3. Turn up media volume; notification volume is separate. Rest chimes run in the open app and are not a guaranteed background alarm.

Spoken encouragement, spoken quotes and wearable/health sync are not part of this release. They need no setup.

Optional · Separate calendar alerts

9. Calendar export

Calendar export is an alternative to push, not required. Using both may produce two alerts.

  1. In Workout time & reminders, choose Export calendar alerts.
  2. iPhone: if your calendar offers an import preview, select a calendar and add the events. If it only displays/downloads the .ics file, import through a calendar service that supports .ics and sync that calendar to the phone.
  3. Android: open the .ics file and use your calendar’s import/add option if available. Otherwise import through the calendar service website; Google Calendar file import uses its desktop web interface.

These are copies for the next 28 days, not a live subscription. Manage outdated events before reimporting after schedule changes. Calendar permissions/alerts belong to your calendar app.

Both platforms · Preserve progress

10. Backups and updates

  1. Recommended: Settings → Your data → Export backup. Keep the JSON file in Files, Downloads or your personal storage.
  2. To restore, choose Import / merge backup. Review the preview before confirming. Do not import another person’s history.
  3. Use Refresh latest version in Settings or apply the update banner. No reinstall is normally needed.

Do not clear site data, delete MENEI or create a replacement account to troubleshoot missing records. Keep the original app and backup, verify the account and exact address, and ask for help. Different browsers/app addresses may hold separate local workspaces.

If something does not work

No confirmation email or invalid sign-in

Check the email spelling and Spam/Junk. If you already created an account, try Reset password once. Open confirmation/recovery links promptly, then return to the installed app to sign in. A creation message alone does not prove email delivery. Report the error without sharing your password or email-link tokens.

It opened the old app

Use the invitation’s exact address, then Settings → Refresh latest version. Keep your icon and saved records. Private-preview and live addresses are separate apps.

AI search is unavailable or incomplete

Sign in while online. Check whether the beta is full or your allowance is used. Manual entries/common setup suggestions remain available. No web search guarantees a complete gym inventory.

Phone and computer disagree

Use the same MENEI account and app address, reconnect both and check Sync now. Review conflicts before choosing a saved copy. Do not delete either device’s records.

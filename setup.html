Cloud & notifications

The app includes the configured cloud connection. Your original device records stay on this device, and you can export backups in Settings.

  1. Open Settings → Cloud account and sign in, or create and confirm your account.
  2. If you used the private beta, import its JSON backup or use the same synchronized cloud account.
  3. Save your reminder time and time zone, then enable push on this device. Notifications need permission at this app’s address.
  4. Check a notification with the app closed and compare a saved workout on a second device.

Account confirmation and recovery

Retain the private beta address too if you still use it. Owners can review these settings under Supabase → Authentication → URL configuration.

Recovery

Settings → Your data provides version 8 exports, import/merge, and saved device snapshots. After an upgrade, Export original backup downloads the previous app’s unmodified device data when it is available.

The repository’s supabase/ folder holds server installation references. Keep private keys and server credentials out of browser files and GitHub.
